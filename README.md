# IX

**Idol Transformation — アイドルを市場との関係から計画・設計・更新する活動。**

IXは、アイドルを単なる商品やコンテンツとしてではなく、アイドルとファンの間に生まれる関係そのものを設計対象として扱う。

## IdolX

**IdolX = Idol Transformation**。

MXの考え方をアイドルに適用し、研究・市場観測・ファン理解・ポジショニング・活動設計・反応計測・学習を循環させる。

```text
observe
  ↓
segment
  ↓
hypothesize
  ↓
position
  ↓
communicate
  ↓
measure
  ↓
learn
  ↓
update
  └────→ market / fans
```

## Core Question

> 人はアイドルとのどのような関係を選択し、その関係はどのように変化するのか？

## DX / MX / BizX / IX / AX

| Layer | 対象 |
|---|---|
| DX | 現場・業務・顧客・データ |
| MX | 市場との関係 |
| BizX | 事業・価値・収益・組織 |
| IX | アイドルとファンの関係・活動 |
| AX | 変化を正確に捉え、実行する |

IXはMXの実験領域であり、BizXへ接続する事業設計の入口でもある。
